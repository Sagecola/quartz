## 步骤1：下载安装（2分钟）
- 访问 [agent.minimaxi.com](https://www.agent.minimaxi.com)
- 点击下载 **Windows 版**（也有 Mac 版）
- 安装后登录账号（手机号/微信即可）

## 步骤2：设定工作目录（关键！）
安装完成后会引导你设置：

1. **头像 → 设置 → 通用**
2. 选择 **"工作目录"**（建议新建一个文件夹，比如 `D:\工作区`）
3. 这个文件夹就是 AI 的"工位"，它可以读写这里面的所有文件

**安全提示**：别选系统盘根目录，选个专门的文件夹，避免 AI 误操作

## 步骤3：开始 Vibe Coding
现在你可以直接对 AI 说人话，让它操作你工作目录里的文件：

### 🎨 场景 A：批量处理照片（零代码）
把 50 张旅游照片丢进工作目录，然后输入：
```
请帮我将这50张照片按拍摄日期整理，创建"2024-03"、"2024-04"这样的文件夹并自动分类，把横屏和竖屏照片分开存放
```
AI 会调用文件系统工具，在你的工作目录里自动创建文件夹、移动文件。

### 🌐 场景 B：生成可分享的网页应用（一键部署）
```
在工作目录下创建一个"今日天气"网页应用，要求：
1. 输入城市名显示实时天气（调用天气API）
2. 背景根据天气变化（晴天蓝色/雨天灰色）
3. 生成完整的HTML文件
4. 部署到线上，我要发链接给朋友
```
MiniMax Agent 会：
- 在工作目录生成代码文件
- **自动部署到 MiniMax Space**（生成 `xxx.space.minimaxi.com` 链接）
- 你直接复制链接发给朋友即可访问

### 📊 场景 C：Excel 报表自动化
把一堆 CSV/Excel 文件丢进工作目录：
```
分析工作目录里所有的销售数据Excel，按月份汇总销售额，生成一个带有图表的可视化HTML报告，并导出为PDF保存到"报表"子文件夹
```
AI 会自动读取多个表格、计算、画图、生成报告。
